# Egypt High School Results Frontend

React application for searching Egyptian High School results.

---

## Technologies

- React
- Vite
- Axios
- Tailwind CSS
- React Icons

---

## Features

- Search by seat number
- Search by Arabic full name
- Loading spinner
- Error handling
- Responsive design
- Arabic interface
- Modern UI

---

## Installation

```bash
npm install

npm run dev
```

---

## Environment Variables

```
VITE_API_URL=http://127.0.0.1:8000
```

For production:

```
VITE_API_URL=https://your-backend-domain
```
