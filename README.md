# Egypt High School Results 2026


![Laravel](https://img.shields.io/badge/Laravel-12-red)
![React](https://img.shields.io/badge/React-19-blue)
![Vite](https://img.shields.io/badge/Vite-7-purple)


A full-stack web application that allows students to search for their Egyptian High School (Thanaweya Amma) results using either their seat number or full Arabic name.

Built with Laravel REST API and React.

---

## Features

- Search by seat number
- Search by full Arabic name
- Arabic name normalization
- Arabic validation messages
- Responsive UI
- Fast search
- RESTful API
- Error handling
- Mobile friendly

---

## Tech Stack

### Backend

- Laravel 12
- PHP 8.2
- MySQL
- Eloquent ORM

### Frontend

- React
- Vite
- Axios
- Tailwind CSS
- React Icons
